    Players and slots

    Up to 64 slots, the engine limit, but at most 24 bots: past 26 or so the game module runs out of its own memory pool and the server dies, so the Add button only offers what fits. The browser, not the server, is what struggles with a crowd. Min players tops the server up with bots, which make way for real players. Reserved slots need a password; use Join to claim one when the server is full. Slot changes restart the server.

    Network

    Tick rate is how often the server updates clients. At 20 that is once every 50ms, which alone reads as about 50ms of ping. 30-40 is smoother; the cost is server CPU.

    Bots

    Kick removes one. To keep the server populated automatically, set Min players on the Match tab.

    Bans

    Nobody is banned.

    Bans match the address, not the player, and only stop new connections - the Connected list above bans and kicks in one step. If everyone shows the same address, name your reverse proxy in TRUSTED_PROXIES so the server can see past it. Ban from the Connected list uses the reason and duration set here; a ban with an end is lifted by itself, and every ban is put back if the game server restarts.

    Upload

    A map, or the game's own content. This server runs on Quake 3's demo assets - six bots and a handful of maps - so if you own the game, upload its pak0.pk3 for all 31 stock maps and the full 32-bot roster. pak0.pk3 to pak8.pk3 are installed as-is; anything else is treated as a map and screened for textures this server does not have. Your files stay in this server's storage, never in the image - EXTRA_PAKS does the same from a URL.

    A zip is unpacked and every pk3 inside it screened. A base pak is several hundred megabytes, so give it a minute. The server restarts when it lands, and every player downloads it once.
